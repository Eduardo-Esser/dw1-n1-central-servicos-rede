# Central de Serviços de Rede

Avaliação N1 — Desenvolvimento Web I (IFC Campus Araquari).
Aplicação Web estática com três páginas, feita apenas com HTML e CSS.

- **Autor:** Eduardo Esser
- **Repositório:** https://github.com/Eduardo-Esser/dw1-n1-central-servicos-rede
- **Publicação:** https://Eduardo-Esser.github.io/dw1-n1-central-servicos-rede/

## Páginas

| Arquivo              | Conteúdo                                                      |
| -------------------- | ------------------------------------------------------------- |
| `index.html`         | Apresentação, botão de suporte e quatro cartões de serviços   |
| `chamados.html`      | Indicadores, formulário de pesquisa e seis chamados fictícios |
| `abrir-chamado.html` | Formulário de abertura de chamado com validações nativas      |

## Estrutura

```
dw1-n1-central-servicos-rede/
- index.html
- chamados.html
- abrir-chamado.html
- README.md
- assets/
    - css/ (reset, global, index, chamados, abrir-chamado)
    - img/
```
